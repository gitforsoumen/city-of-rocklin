# City of Rocklin — website

A three-page website built from the "City of Rocklin" Figma design.

- `index.html` — Home
- `events.html` — Events
- `event-details.html` — Event Details (Robin Trower)

Plain HTML, CSS and a little JavaScript. No build step is needed: GitHub Pages serves the files as they are.

Design: Soumen Dey — UI/UX Designer
